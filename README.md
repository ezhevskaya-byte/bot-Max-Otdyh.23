# Отдых23 — AI-бот для MAX

Бот гостевого дома **«Отдых23»** для мессенджера MAX: сбор заявок на бронирование, подбор номеров, отправка заявки администратору Оксане.

## Возможности

- Диалог с гостями в MAX
- Поэтапный сбор данных: даты, состав, возраст детей, пожелания по кроватям
- Подбор **Семейной** (2–5 гостей) и **Комфорт** (2–3 гостя)
- **Цены не показываются** — только в сообщении о том, что стоимость уточнит администратор
- Просмотр заявки гостем и кнопка **«Связаться с администратором»**
- Автоотправка заявки администратору в MAX
- Заготовка интеграции **BookingLite** (доступность, черновик брони)

## Быстрый старт

### Требования

- Node.js 20+

### Установка

```bash
cp .env.example .env
# Заполните MAX_BOT_TOKEN, ADMIN_MAX_USER_ID, при необходимости AI_API_KEY
npm start
```

Режим разработки с перезапуском:

```bash
npm run dev
```

### Webhook MAX

Укажите в настройках бота MAX URL:

```
POST https://ваш-домен/webhook/max
```

Проверка здоровья:

```
GET /health
```

### Тесты

```bash
npm test
```

## Сценарий бронирования

1. Гость пишет «забронировать» или нажимает **Забронировать номер**
2. Бот собирает: заезд → выезд → взрослые → дети → возрасты → кровати
3. Подбор подходящих номеров (без цен)
4. Гость выбирает вариант
5. Показ заявки для проверки
6. Кнопка **Связаться с администратором** → заявка уходит Оксане в MAX
7. При включённом BookingLite — опционально создаётся черновик брони

## Типы номеров (config/rooms.json)

| Тип | Гостей | Раскладка |
|-----|--------|-----------|
| Семейная | 2 | Двуспальная + зона отдыха |
| Семейная | 5 | Двуспальная + 3 односпальные |
| Комфорт | 2 | Двуспальная |
| Комфорт | 3 | Двуспальная + доп. место |

## BookingLite (подключение позже)

1. В `.env` задайте:
   ```
   BOOKINGLITE_ENABLED=true
   BOOKINGLITE_API_URL=https://...
   BOOKINGLITE_API_KEY=...
   ```
2. Реализуйте эндпоинты в `integrations/bookinglite/client.js` по документации BookingLite
3. `adapter.js` уже фильтрует номера по доступности и создаёт черновик после подтверждения

## AI-слой

Основная логика — **детерминированный FSM** (`dialog-handler.js`), стабильный для продакшена.

`ai-assistant.js` + `prompts/*.md` — для расширения свободного диалога; подключается при наличии `AI_API_KEY`.

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `MAX_BOT_TOKEN` | Токен бота MAX |
| `MAX_WEBHOOK_SECRET` | Секрет webhook |
| `ADMIN_MAX_USER_ID` | ID Оксаны в MAX |
| `AI_API_KEY` | Ключ LLM (опционально) |
| `BOOKINGLITE_*` | Интеграция PMS (опционально) |
