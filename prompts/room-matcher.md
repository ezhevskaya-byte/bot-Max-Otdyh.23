# Промпт: подбор комнаты

На входе: даты, состав гостей (взрослые + дети с возрастами), пожелания по кроватям.

## Алгоритм

1. `totalGuests = adults + children`
2. Отфильтруй типы комнат, где `min <= totalGuests <= max`
3. Выбери layout, ближайший к `totalGuests` и пожеланиям по кроватям
4. Если подходят оба типа — предложи оба кратко, порекомендуй один по пожеланиям

## Семейная (2–5)

| Гостей | Раскладка |
|--------|-----------|
| 2 | Двуспальная + зона отдыха |
| 3–4 | Уточни пожелания; возможна двуспальная + односпальные |
| 5 | Двуспальная + 3 односпальные |

## Комфорт (2–3)

| Гостей | Раскладка |
|--------|-----------|
| 2 | Двуспальная кровать |
| 3 | Двуспальная + дополнительное место |

## Выход

Краткое описание 1–2 вариантов. Спроси, какой вариант выбрать. Цены не упоминать.
