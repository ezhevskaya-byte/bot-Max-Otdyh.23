Делюкс — второй этаж

Просторная и светлая комната категории «Делюкс» на втором этаже — отличный вариант для гостей, которые ценят комфорт, уют и спокойную атмосферу отдыха у моря.

Комната хорошо подойдёт:
— для пары;
— для семьи с ребёнком;
— для размещения до трёх гостей;
— для гостей, которым важно больше пространства и удобства во время отдыха.

Для размещения до четырёх гостей возможно использование полноценного двуспального дивана.

Детская кроватка предоставляется по запросу для ребёнка до 4 лет, входит в стоимость. При размещении 2 или 3 гостей установить можно. При размещении 4 гостей детскую кроватку не устанавливаем; если нужны 4 гостя и кроватка — лучше подойдёт «Семейная».

В комнате:
— двуспальная кровать или две односпальные кровати — по предварительному запросу;
— полноценный диван;
— ортопедические беспружинные матрасы;
— гипоаллергенные подушки и одеяла;
— кондиционер;
— телевизор;
— холодильник для напитков;
— сейф;
— Wi-Fi;
— собственный санузел с душем;
— небольшой французский балкон с сушкой для белья.

Для гостей предоставляется:
— постельное бельё premium-класса из 100% хлопка;
— полотенца из турецкого текстиля premium-качества (100% хлопок);
— полотенца для бассейна;
— минимальный набор косметических средств;
— одноразовые тапочки для взрослых.

Комната создаёт ощущение просторного и уютного пространства, куда приятно возвращаться после моря, прогулок и вечернего отдыха.

Благодаря полноценному дивану категория «Делюкс» особенно удобна для семей с детьми, длительного проживания и размещения 3–4 гостей.

На территории гостевого дома:
— подогреваемый бассейн;
— уютная терраса для приёма пищи;
— зелёный двор с живыми растениями;
— спокойная домашняя атмосфера без лишней суеты.

Категория «Делюкс» отлично подойдёт гостям, которые хотят совместить комфорт, простор и приятную атмосферу отдыха у моря.
